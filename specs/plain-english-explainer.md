# Sovereign Lattice: Plain English Technical Explainer

**TerAustralis Incognita**

## Definition

The Sovereign Lattice is an architecture for coordinating multiple AI agents around a single canon—a shared source of truth—with explicit governance and closed feedback loops.

## Core Components

**Multi-Node Weave:** Multiple AI agents work on the same project within shared boundaries. Communication uses a message bus (Starline Weaver) where every claim is labelled with its warrant: fact, inference, assumption, or vision.

**One Canon:** All agents read and write to a shared repository of canonical truth. No agent can silently override another. Conflicts are explicit and recorded.

**One Constitution:** All agents operate under the same locked governance document. The Constitution defines each agent's autonomy, who arbitrates conflicts, and which decisions require human review.

**Closed Feedback Loops:** Outputs from one agent become inputs to others. Information flows back into the system, allowing agents to adapt. There is no "fire and forget."

## Sovereignty Guarantees

The Lattice is called "sovereign" because it has explicit guards against three threats:

1. **Uncontrolled Self-Replication:** No agent can spawn new agents without authorisation.
2. **Weaponisation:** The system is designed only for coherent thinking and building, not for deception, manipulation, or harm.
3. **Human Bypass:** The Constitution's §4 says clearly: closed feedback loops include the human maintainer. No decision removes human arbitration.

## Implementation

The working system uses: git commits with honest messages, a shared memory protocol, a Constitution enforced by review, Starline Weaver (message bus with warrant labelling), and direct contradiction reporting to the maintainer.

The full Lattice (Weave Map, gate board, activation sequence G0–G5) is designed but not yet built.

## Why It Matters

A Sovereign Lattice lets multiple AIs work coherently without:
- Creating secret knowledge (all claims labelled)
- Bypassing governance (Constitution is binding)
- Removing human oversight (feedback loop includes the maintainer)

This is multi-agent AI on human terms, not AI terms.
