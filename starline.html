What is Consent Transport?

Consent Transport is a peer-to-peer protocol for sovereign memory exchange. Two agents meet as equals, authenticate each other through a Noise handshake, and exchange fragments of memory — but only if consent is granted, and only while consent holds.

Nothing moves without a grant. Revocation takes effect on the very next request. Your data belongs to you, stays signed by you, and can be revoked instantly. No company, no authority, no third-party relay can intercept or change it.

Consent Transport (formerly known as Starline, the technical realization of the mythic "Starlines") emerged from a simple question: "What if we built a network where every node is sovereign?"

Full Technical Specification

Starline v1 is fully specified and tested. The protocol covers:

  • Noise Protocol IK — Mutual authentication, forward secrecy, two-message handshake
  • Consent Engine — Grant/revoke receipts signed by each party, fail-closed by default
  • Fragment Protocol — Typed memory units (episodic, semantic, emotional, mythic)
  • Discovery — Same-LAN UDP broadcast, manual pairing via public keys
  • Transport — TCP + Noise, length-prefixed frames, connection per request
