## How to use this table

1. Find your need in the left column
2. Read the file in column 2
3. Check the Status: Built = canonical; Vision = speculative; Partial = incomplete
4. Note the Privacy: Public = safe to reference; (Private materials not listed here)
5. The "When" column tells you the right moment to read it

## Quick lookups by task type

**I'm starting a session. Read in order:**
1. `memory/CORE.md`
2. `memory/state/CURRENT.md`
3. This INDEX.md
4. Whatever the CONTEXT-PACK says

**I'm making a large change. Read:**
1. `docs/governance/Constitution.md`
2. `AGENTS.md` (your role)
3. `docs/governance/The-Incognita-Rule.md` (honesty)
4. Related files from the table above

**I'm collaborating with another AI. Read:**
1. `docs/ai/AI-Workflow.md`
2. `docs/governance/AI-Governance.md`
3. `docs/agents/` (current roles)
4. `memory/collaboration/AI-HANDOFF.md`

**I'm understanding repository structure. Read:**
1. `STATUS.md`
2. `docs/architecture/SystemMap.md`
3. `docs/governance/Project-Boundaries.md`
4. `CHANGELOG.md` (recent state)

**I'm stuck or need to know what we don't know. Read:**
1. `memory/state/OPEN-QUESTIONS.md`
2. `memory/evidence/CONFLICTS.md`
3. `memory/evidence/HYPOTHESES.md`

**I need to update memory before finishing work. Modify:**
1. `memory/state/CURRENT.md` (if repo state changed)
2. `memory/state/DECISIONS.md` (if decisions made)
3. `memory/state/OPEN-QUESTIONS.md` (if blockers changed)

6. `memory/evidence/CONFLICTS.md` (if sources disagreed)
7. `memory/collaboration/CONTEXT-PACK.md` (if next session needs to know)
